`node web/tests/prepare-telemetry.mjs`로 임시 정적 테스트 페이지를 준비하고 Vite의 `/audit-check.html`을 열어 검증한다. `tests` 디렉터리는 Vite 허용 목록 밖이므로 원본 HTML을 직접 서빙하지 않는다. fetch를 테스트 내부에서 대체하므로 실제 로그 API에는 전송하지 않는다. 18개 페이지 경로, 중첩 SVG·모달·체크박스·선택·비활성 요소·링크·제출·키보드·미디어·shadow DOM·입력값 제외·원문 오류·기록 실패 격리 등 62개 검사를 수행한다. 검증 후 생성된 HTML·캐시를 삭제한다. 동일한 테스트 본문은 별도 DOM 실행 환경에서도 실행할 수 있다.
