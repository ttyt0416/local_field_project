# I2I 생성 컴포넌트

모델 family는 라우트가 prop으로 전달한다. 모델 탭은 onselect 콜백으로 상위 상태만 바꾸며 페이지 이동이나 전체 새로고침을 하지 않는다. 상위 keyed 블록에서 family마다 컴포넌트를 교체해 폼·프리셋·모달 상태를 분리한다.

설치된 Illustrious 체크포인트가 없으면 안내를 표시하고 생성은 비활성화하되 프리셋 사용은 유지한다. 긴 체크포인트명은 그리드 자식과 버튼의 최소 너비를 제한하고 한 줄 말줄임 및 title로 표시한다. 선택 모달의 모델명은 줄바꿈한다.

## MOSS

MOSS는 T2I 전용이므로 I2I 모델 탭·설정·요청에서 제외한다. 기존 family=moss I2I 주소는 MOSS T2I 페이지로 이동한다. 소스 선택창에서 MOSS 생성물을 찾을 때도 T2I만 표시한다. 다른 편집 모델의 다중 참조 UI는 유지한다.

Qwen 2.1 Turbo 탭은 한 장 수정(I2I)과 원본 포함 최대 10장 참조 생성(R2I)을 제공한다. 추가 참조가 있으면 페이지 제목이 R2I로 바뀐다. 참조 추가·정렬·삭제와 기기/저장소 선택을 재사용하고 원본 <image1>, 추가 참조 <image2>~<image10> 순서를 안내한다. 공식 8스텝·CFG 1·Euler·전용 스케줄을 고정하고 Denoise·negative prompt를 노출하지 않는다. 프리셋과 보관함 재생성에 동일한 family·참조를 전달한다.

Anima·Illustrious I2I는 T2I와 같은 enhanceImagePrompt 유틸과 vLLM 개선 API를 사용한다. Anima는 태그+자연어, Illustrious는 검증된 태그를 반환한다. Qwen 2.1은 태그 검색 없이 자연어 수정 지시만 반환하며 원문 언어·문구·참조 관계를 보존하고 보지 않은 이미지 내용을 추측하지 않는다. 원본·참조 이미지는 기존 순서대로 생성 인코더에 전달한다. ComfyUI 내부 TextGenerate와 별도 강화 모델의 준비 여부에 의존하지 않는다.

프롬프트 개선은 T2I와 같이 기본 꺼짐이며 켠 뒤 개선 버튼으로 결과를 받아 편집한다. 개선 중에는 중복 요청과 생성을 막고 실패는 toast로 표시한다. 생성 payload에 활성 상태와 improved_prompt를 함께 전달한다. 프리셋과 보관함 재생성도 두 값을 저장·복원한다. 원문·저장 문장·Embedding을 변경하면 이전 결과를 비워 재개선을 요구한다.
수정 지시/긍정·부정 프롬프트 아래 PromptLibrary로 이미지용 문장을 저장하거나 현재 입력 뒤에 추가한다. Reference edit의 부정 입력은 기존과 같이 숨긴다.

생성 중이 아닐 때 왼쪽 결과 패널 상단에도 실행 버튼을 표시한다. 하단과 같은 generationButton snippet을 사용하며 form 속성으로 설정 폼을 제출하므로 입력 제약·비활성화·로딩 상태가 동일하다.
