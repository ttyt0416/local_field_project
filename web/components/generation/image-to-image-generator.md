# I2I 생성 컴포넌트

모델 family는 라우트가 prop으로 전달한다. 모델 탭은 onselect 콜백으로 상위 상태만 바꾸며 페이지 이동이나 전체 새로고침을 하지 않는다. 상위 keyed 블록에서 family마다 컴포넌트를 교체해 폼·프리셋·모달 상태를 분리한다.

긴 체크포인트명은 그리드 자식과 버튼의 최소 너비를 제한하고 한 줄 말줄임 및 title로 표시한다. 선택 모달의 모델명은 줄바꿈한다.

## MOSS

MOSS는 T2I 전용이므로 I2I 모델 탭·설정·요청에서 제외한다. 기존 family=moss I2I 주소는 MOSS T2I 페이지로 이동한다. 소스 선택창에서 MOSS 생성물을 찾을 때도 T2I만 표시한다.


Anima I2I는 T2I와 같은 enhanceImagePrompt 유틸과 vLLM 개선 API를 사용한다. Anima는 태그와 자연어를 반환한다.

프롬프트 개선은 T2I와 같이 기본 꺼짐이며 켠 뒤 개선 버튼으로 결과를 받아 편집한다. 개선 중에는 중복 요청과 생성을 막고 실패는 toast로 표시한다. 생성 payload에 활성 상태와 improved_prompt를 함께 전달한다. 프리셋과 보관함 재생성도 두 값을 저장·복원한다. 원문·저장 문장을 변경하면 이전 결과를 비워 재개선을 요구한다.
긍정·부정 프롬프트 아래 PromptLibrary로 이미지용 문장을 저장하거나 현재 입력 뒤에 추가한다.

생성 중이 아닐 때 왼쪽 결과 패널 상단에도 실행 버튼을 표시한다. 하단과 같은 generationButton snippet을 사용하며 form 속성으로 설정 폼을 제출하므로 입력 제약·비활성화·로딩 상태가 동일하다.

## 공용 사용

Local Field 로그인 상태·인증 리디렉션 없이 공용 기능을 사용한다. 계정 토큰을 API 요청에 전달하지 않는다.

MiniMax H3-Image I2I 탭은 소스를 Picture 1로, 추가 참조 최대 15장을 Picture 2부터 전달한다. 기기·업로드·생성 콘텐츠 선택과 참조 순서 변경·제거를 지원하며 재생성 시 참조도 복원한다. multipart 파일 순서와 file_index를 함께 구성한다. CFG 1·6스텝·Denoise 1을 사용하고 부정 입력과 Denoise 조절을 숨긴다.

가로·세로 입력에는 최소·최대·배수 제한을 두지 않는다. 원본 크기 적용은 원래 width·height를 반올림·상한 보정 없이 그대로 사용한다.
