# 프롬프트 저장·불러오기

image/video별 사용자 저장 문장을 관리한다. 기본 모드는 현재 입력 저장과 목록에서 뒤에 추가 버튼을 제공하고, manage 모드는 별도 관리 페이지의 새 문장·검색·수정·삭제 UI를 제공한다. 삭제는 재확인 후 수행한다. API 오류는 Toast, 작업 중 버튼은 loading/disabled 처리한다.

불러오기는 적용 순간의 value와 appendPrompt를 사용하므로 입력을 덮어쓰지 않는다. 이미지 문장은 쉼표, 동영상 문장은 줄바꿈으로 구분하며 5000자를 넘으면 원문을 유지하고 오류를 표시한다. 모달의 편집은 저장 직전까지 원본 문장을 바꾸지 않는다.
