# VIDEO GEN 프리셋 모달

영상 생성 프리셋의 저장·수정 모달이다. 생성 화면 또는 Vault detail에서 current prompt, mode, checkpoint, LoRA name·strength, ratio, normalized Base MP, optional learned 3D upscale Target MP, sampler, scheduler, 길이, FPS, steps, PDD state, seed를 initial value로 받아 저장한다. Seed는 필수값이 아니며 blank이면 seed 관련 key를 저장하지 않는다. direct width/height preset field는 없고, selected ratio와 Base MP 및 optional Target MP만 saved semantic resolution이다. learned 3D upscale은 live ComfyUI capability가 있을 때만 선택 가능하며 PDD와 함께 저장하지 않는다. checkpoint는 current mode의 folder-filtered modal에서 Eros와 Dasiwa를 표시하고 Dasiwa가 default다. LoRA field는 `MiniMax/` allowlist만 folder-filtered modal에서 multi-select하고 each strength를 보존하며 sampler/scheduler는 IMAGE GEN과 같은 공용 choice modal에서 current live ComfyUI choice를 선택한다. load는 current mode options를 받은 뒤 checkpoint, available LoRA, sampler, scheduler를 적용한다. 공용 `Modal`의 `80dvh` 최대 높이와 내부 스크롤을 사용한다.
