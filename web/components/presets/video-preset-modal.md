# VIDEO GEN 프리셋 모달

영상 생성 프리셋의 저장·수정 모달이다. 생성 화면 또는 Vault detail에서 현재 prompt, mode, checkpoint, LTX LoRA name·strength, 크기, 길이, FPS, seed를 초기값으로 받아 저장한다. 선택한 필드만 `video` 타입으로 저장한다. checkpoint는 current mode의 folder-filtered modal에서 하나를 선택하며 `MINIMAX` family에는 Eros와 Dasiwa만 표시되고 Dasiwa가 default다. `LTX` family는 verified LTX core bundle이 live ComfyUI에 있을 때 선택 가능하다. LTX checkpoint와 LoRA field를 함께 선택하면 live `LTX/` LoRA만 folder-filtered modal에서 multi-select하고 각 strength를 보존한다. checkpoint를 저장하면 compatible mode도 함께 저장한다. 크기는 API에서 `width`·`height`, seed 무작위 여부는 `random_seed`로 보존하며, 수정 시 이 값을 `VIDEO GEN` 필드 선택 상태로 복원한다. 공용 `Modal`의 `80dvh` 최대 높이와 내부 스크롤을 사용한다.
