# VIDEO GEN 프리셋 모달

영상 생성 프리셋의 저장·수정 모달이다. 생성 화면 또는 Vault detail에서 현재 prompt, mode, LTX/MiniMax family, checkpoint, LoRA name·strength, LTX I2V upscale, 크기, 길이, FPS, seed를 초기값으로 받아 저장한다. 선택한 필드만 `video` 타입으로 저장한다. checkpoint는 current mode의 folder-filtered modal에서 하나를 선택하며 `MINIMAX` family에는 Eros와 Dasiwa만 표시되고 Dasiwa가 default다. `LTX` family는 verified LTX core bundle이 live ComfyUI에 있을 때 선택 가능하다. LoRA field는 current checkpoint family의 `MiniMax/` 또는 `LTX/` allowlist만 folder-filtered modal에서 multi-select하고 각 strength를 보존한다. family를 양방향으로 전환하거나 다른 family checkpoint를 고르면 current LoRA selection을 비운다. LTX family와 selected checkpoint는 `video_model_family` 및 checkpoint로 독립 저장하고, load는 current mode options를 받은 뒤 family→checkpoint→family-compatible LoRA 순서로 적용한다. LTX I2V의 선택된 `업스케일 사용` field는 `upscale` boolean으로 저장·복원한다. 공용 `Modal`의 `80dvh` 최대 높이와 내부 스크롤을 사용한다.
