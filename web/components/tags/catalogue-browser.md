# 로컬 캐릭터·아티스트·시리즈

공유 CatalogueBrowser는 로컬 카탈로그 API만 사용하며 이름·태그 검색, 정렬, 페이지, 트리거 복사·추가와 시리즈별 캐릭터 탐색을 제공한다. 서버에 초기 데이터가 없으면 준비 실패와 원인을 표시하고 외부 검색·이미지 요청으로 대체하지 않는다. 페이지/필터 변경의 늦은 응답은 무시한다.

화면 안내에는 결과 개수와 갱신일만 표시하고 로컬 카탈로그 출처 문구는 표시하지 않는다. 접근성 이름과 오류 안내에서도 로컬이라는 표현을 생략한다.

세 종류 카드의 thumb_url은 서버가 발급한 해당 이미지 전용 서명 주소다. SERVER_URL과 결합해 공유 ImageMedia의 external 소스로 직접 표시한다. 기존 보관함 Storage 이미지처럼 브라우저 기본 지연 로딩·캐시·확대 갤러리를 사용하며 Blob 중간 다운로드를 하지 않는다. 주소는 Local Field 서버만 가리키며 export 토큰을 포함하지 않는다. 로컬 파일이 없는 항목에는 등록된 썸네일이 없다는 placeholder를 표시하며 이미지 표시 오류는 ImageMedia의 선택적 onerror callback으로 Toast에 전달한다.
