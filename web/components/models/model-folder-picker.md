# 모델 폴더 선택

Civitai 다운로드의 저장 위치 선택과 파일 관리의 이동 위치 선택에 사용하는 공용 모달이다. 지정된 모델 종류의 `GET /models/folders`를 읽어 빈 폴더를 포함한 하위 폴더를 탐색하고 `POST /models/folders`로 현재 위치에 폴더를 만든다. 선택은 상대 경로를 onconfirm으로 전달하며 실제 다운로드·이동은 부모에서 처리한다.

열기·모델 종류·초기 위치가 바뀌면 목록을 다시 읽는다. 닫힌 뒤 늦게 도착한 응답은 무시한다. 읽기 실패 시 선택을 막고 재시도를 제공하며 모든 API 오류를 Toast로 표시한다. 폴더 생성 또는 부모 작업 진행 중에는 닫기·선택·탐색을 막는다.
