# Navbar

The authenticated navbar polls Local Field `GET /hardware/metrics` immediately after authentication and every 5 seconds. CPU, GPU, RAM, and DISK are always rendered in a dedicated two-column grid container. The outer navbar uses `justify-between`: existing account, health, theme, and menu controls remain in the left group while the metrics container is its right-side sibling. Browser code never calls the independent hardware-monitor directly, so the monitor remains outside public browser/CORS access; Local Field server authenticates the user and proxies the internal request. On the first consecutive poll failure, the navbar hides stale values and shows one safe negative Toast; it suppresses repeated Toasts until a successful poll resets the failure state.
