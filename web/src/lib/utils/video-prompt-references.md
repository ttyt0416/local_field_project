# 동영상 프롬프트 참조 입력

선택된 참조 순서를 실제 생성의 Picture·Video·Audio 번호와 동일하게 구성한다. I2V는 첫 프레임, FL2V는 첫·마지막 프레임, R2V는 이미지 정체성·영상 움직임·오디오 역할을 명시한다. 후속 구간은 아직 생성되지 않은 마지막 프레임을 Picture 1로 예약하고 미리보기를 만들지 않는다. 후속 R2V만 사용자 이미지 참조를 Picture 2부터 유지하며 이전 구간의 영상·오디오 참조는 보내지 않는다.

이미지 미리보기는 원본 비율을 유지하고 긴 변 최대 768픽셀인 JPEG로 만들어 vLLM image_url 입력에 전달한다. 저장 이미지 원본 읽기는 호출자가 인증된 uploads source API로 수행한다. 영상·음성은 파일명과 역할만 전달하므로 해당 내용을 보거나 들었다고 간주하지 않는다. 이미지 디코딩·다운로드 실패는 호출자의 기존 try/catch와 toast로 전달한다.
