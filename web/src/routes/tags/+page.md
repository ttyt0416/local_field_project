# 태그 탐색기

탭 순서는 Danbooru → Gelbooru → 캐릭터 → 아티스트 → 시리즈다. 기존 Danbooru 검색과 카드 UI를 공유 BooruBrowser로 분리하고, Gelbooru는 전체 태그 스냅샷을 로컬 DB에서 검색한다. AnimaDex 세 탭도 로컬 DB만 조회하며 export 실패 시 해당 원인을 표시한다. 외부 검색 API로 대체하지 않는다.

선택한 태그 textarea는 모든 탭에서 공유하고 추가 버튼은 기존 내용 뒤에 이어 붙인다. 캐릭터의 시리즈명 또는 시리즈 카드의 캐릭터 보기로 같은 시리즈 필터를 적용하며 해제할 수 있다. 탭 전환은 검색 컴포넌트를 재생성해 이전 비동기 응답과 상태를 격리한다. 인증·라우트/클릭 기록은 기존 공통 처리를 사용한다.

페이지 설명과 각 탭 안내에서 로컬 태그·로컬 카탈로그 문구를 표시하지 않는다.
