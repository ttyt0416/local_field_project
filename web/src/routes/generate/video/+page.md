# MiniMax H3 동영상 생성 화면

I2V·FL2V·R2V를 탭으로 선택한다. 각 입력은 기기 저장소 또는 업로드·생성 콘텐츠 선택 모달에서 고를 수 있다. 모달에서 선택한 기존 파일은 `file_id`로 전송해 서버가 소유권 확인 후 재사용하고, 기기 파일은 생성 submit 시 multipart 요청으로 전송한다. R2V는 참조 이미지·동영상·오디오를 사용한다. 선택한 시작 이미지·첫/마지막 프레임·참조 이미지·참조 동영상은 실제 미리보기로 표시하고, 참조 오디오는 오디오 아이콘 카드로 표시한다. 미리보기 목록은 최소 2열 그리드다. 업로드 콘텐츠 화면과 저장 콘텐츠 선택 모달의 목록은 page size 10이며 ChevronLeft·ChevronRight 버튼으로 페이지를 이동한다.

페이지는 생성 결과와 서버가 기록한 상태를 표시한다. 생성 설정 헤더의 저장 아이콘은 현재 영상 생성 설정을 `VIDEO GEN` 프리셋으로 저장하는 모달을 연다. duration은 고정된 최대·최소 제한 없이 초 단위로 입력하고, 생성 버튼을 누르면 Backend가 ComfyUI queue를 제출하며 화면을 이동해도 서버 worker가 계속 처리한다. 프런트는 전역 generation job store를 통해 SSE를 구독하므로 진행 중인 route 이동과 새로고침을 복구한다. 생성 화면은 store의 가장 최근 job을 결과 패널에 가져오지 않고, 해당 화면에서 새로 등록한 job만 표시해 이전 완료 결과를 초기화한다. 생성 중에는 경과 시간을 분·초로 표시하고 완료·실패 후에는 DB에 저장된 고정 소요 시간을 표시한다. 가로와 세로 바꾸기 아이콘 버튼은 두 크기 값을 교환하며 duration과 FPS는 유지한다. 선택된 시작 이미지·첫/마지막 프레임·참조 이미지·참조 동영상 카드마다 원본 media metadata `가로 × 세로`와 해당 카드 전용 크기 적용 버튼을 표시한다. 적용 크기는 원본 비율을 최대한 유지하면서 MiniMax H3의 가로·세로 최대 1344와 32배수 제약 안으로 맞추며, `이 사이즈 사용` 버튼을 누르면 계산한 값을 영상 크기 입력에 적용한다. R2V에서 여러 이미지·동영상을 선택한 경우에도 각 자산별로 독립적으로 동작하고 local 항목을 삭제하면 이동한 index의 metadata를 다시 측정한다. Seed는 `무작위 시드`가 선택되면 입력을 비활성화하고 서버에 무작위 생성을 요청하며, 선택을 해제하면 입력한 seed를 전송한다. 실제 Storage 업로드와 ComfyUI queue 제출은 생성 버튼을 누른 뒤에만 시작한다. 모바일 submit 버튼은 불투명한 하단 고정 영역에 표시하고 데스크톱에서는 폼 흐름으로 되돌린다.

프롬프트 개선을 켜면 `프롬프트 개선` 버튼이 `POST /generation/video/enhance-prompt`를 호출하고 개선 결과를 별도 textarea에 표시한다. 출력 언어는 한글·영어·일어 checkbox를 하나 이상 복수 선택할 수 있으며, 숫자와 특수기호는 선택 언어와 관계없이 허용된다. 결과는 AtlasCloud 우선 6블록 형식으로 표시되고, prompt·mode·duration·언어 선택을 바꾸면 이전 개선 결과를 비워 stale prompt 제출을 막는다.
페이지의 콘텐츠 탭과 보관함 탭은 로그인 화면에서 사용하는 공용 `components/tabs/tab.svelte`를 재사용한다. 선택된 모든 미디어 카드의 우측 상단에는 Lucide X 해제 버튼이 있으며, 생성 중에는 영상 job을 backend cancel endpoint로 취소할 수 있다. 완료·실패 토스트는 동일 job terminal 상태마다 한 번만 표시한다. VIDEO GEN 프리셋 불러오기는 저장된 프리셋 목록에서 선택한 필드만 현재 입력에 적용한다.
