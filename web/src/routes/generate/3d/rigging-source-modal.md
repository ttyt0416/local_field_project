# 리깅 소스 GLB 선택

동영상 생성의 단일 소스 선택 흐름에 맞춰 공용 Modal·Tab·SearchBar·ImageMedia·버튼을 재사용한다. 선택 버튼으로 모달을 열고 기기 저장소 또는 저장된 콘텐츠에서 한 모델을 선택하면 즉시 모달을 닫는다. 기기 파일은 .glb 및 200 MiB 제한을 확인한다.

저장된 콘텐츠는 기존 `GET /vault/3d`의 검색·정렬·페이지 API로 읽고 완료된 MESH 결과만 표시한다. 각 카드에 원본 이미지와 품질·생성 시각·용량을 표시한다. 리깅이나 진행 중인 결과만 있는 페이지에서도 페이지 이동을 제공한다. 새 요청 ID와 mount 상태로 오래된 응답을 무시하며 조회 오류는 부모 Toast에 전달한다. 검색어·정렬 변경은 첫 페이지로 이동하고 모달을 다시 열면 기본 상태로 초기화된다.

기기 File 또는 저장된 generation ID·모델 URL을 부모에게 전달한다. 선택 단계에서는 업로드하거나 리깅 작업을 시작하지 않는다.

저장된 모델 카드의 `3D 미리보기`를 누르면 공용 ModelViewer로 실제 GLB를 열어 회전·확대할 수 있다. 한 번에 한 카드만 모델을 로드하고 다른 카드 선택, 페이지·검색·정렬·위치 변경, 모달 닫기에서 미리보기를 해제한다. 기본 목록은 원본 이미지 또는 아이콘으로 표시해 모든 GLB를 동시에 받지 않는다. 모델 확인과 소스 확정은 별도 버튼으로 동작한다.
