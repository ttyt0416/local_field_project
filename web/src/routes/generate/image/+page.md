# 이미지 생성 결과 표시

이미지 생성 결과 응답에는 Storage 절대 URL 또는 기존 상대 URL을 사용한다. 생성 진행 중 SSE 연결 상태 자체는 사용자 문구로 표시하지 않으며, 새 LoRA 슬롯의 strength 기본값은 `1.0`이다. 모바일 이미지 생성 버튼은 불투명 배경의 하단 고정 컨테이너 안에 표시하고 데스크톱에서는 기존 폼 흐름으로 표시한다. 프리셋 저장 모달이 열린 동안 배경 페이지 스크롤을 잠그며, 긴 모달 본문은 모달 내부에서 스크롤한다.

프리셋 저장 아이콘은 이름과 저장할 항목을 선택해 새 프리셋을 만들거나 기존 프리셋을 덮어쓴다. 불러오기 아이콘은 저장된 `t2i` 프리셋을 표시하고, 선택한 프리셋의 저장 항목만 현재 설정에 적용한다. 프리셋 이름 입력에는 placeholder를 사용하지 않는다.

이미지 상세에서 `이 설정으로 다시 생성`을 선택하면 해당 이미지의 긍정·부정 프롬프트, 체크포인트, LoRA별 strength, CFG, Steps, 이미지 크기와 seed를 이미지 생성 화면에 불러온다.
