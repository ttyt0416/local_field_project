# 이미지 생성 결과 표시

이미지 생성 응답 URL이 독립 Storage의 절대 URL이면 `ImageMedia`에 `external` 소스로 전달한다. Storage 연동이 비활성화된 개발 환경에서 반환되는 기존 상대 URL은 `server` 소스로 처리한다. 생성 진행 중 SSE 연결 상태 자체는 사용자 문구로 표시하지 않으며, 새 LoRA 슬롯의 strength 기본값은 `1.0`이다. 모바일 이미지 생성 버튼은 화면 하단에 고정하고 데스크톱에서는 기존 폼 흐름으로 표시한다.

프리셋 저장 아이콘은 이름과 저장할 항목을 선택해 새 프리셋을 만들거나 기존 프리셋을 덮어쓴다. 불러오기 아이콘은 저장된 `t2i` 프리셋을 표시하고, 선택한 프리셋의 저장 항목만 현재 설정에 적용한다.
