# 콘텐츠 상세

콘텐츠 상세 페이지는 진입할 때마다 `GET /vault/images/{generation_id}`를 호출하고 서버에서 조회수를 증가시킨다. 초기 로딩 중에도 페이지 배경·뒤로가기·`콘텐츠 상세` 제목을 유지하고 실제 콘텐츠 영역만 `LoadingSpinner`로 표시한다. Storage signed URL 또는 인증 이미지 프록시로 결과 이미지를 표시하며, 무배경·무테두리 헤더에는 `콘텐츠 상세` 제목과 조회수만 표시한다. 완료 상태의 `IMAGE · 완료` 텍스트와 별도 타입 아이콘 container는 표시하지 않는다.

favorite 버튼은 제목 영역이 아니라 이미지 우측 하단에 배치하고, 테두리 없는 배경색 `filled` 아이콘 버튼을 사용한다. 다운로드 아이콘 버튼도 이미지 우측 하단에 함께 배치하며 favorite와 같은 primary 색상·디자인의 `filled` 버튼으로 표시하고 인증된 media URL로 파일을 내려받는다. 버튼은 `PATCH /vault/images/{generation_id}/favorite`로 상태를 저장한다. 페이지 하단의 red 콘텐츠 삭제 버튼은 확인 모달을 연다. 확인 후 `DELETE /vault/images/{generation_id}`가 성공하면 보관함으로 이동한다. 생성 파라미터에서는 파일 경로를 표시하지 않으며 LoRA는 `이름 / strength` 형식으로 표시한다. 사용된 긍정·부정 프롬프트 제목 행은 `space-between`으로 배치하고 각각의 `Copy` 아이콘 버튼으로 클립보드에 복사한다. `이 설정으로 다시 생성`을 선택하면 긍정·부정 프롬프트와 체크포인트, LoRA별 strength, CFG, Steps, 이미지 크기, seed를 `imageGenerationStore`에 저장하고 이미지 생성 화면으로 이동한다. `이미지 편집`은 crop과 90도 단위 회전을 Canvas로 미리보고 원본을 보존한 새 콘텐츠를 저장한다. lightbox의 확대·축소 버튼은 100%·125% 단위로 최대 400%까지 표시 크기만 변경하며 파일 자체는 변경하지 않는다. 페이지 제목은 `콘텐츠 상세`이며 공용 `Typography`의 축소된 `display` variant를 사용한다.
