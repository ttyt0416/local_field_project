# 업로드 콘텐츠 상세

`/uploads/{file_id}`는 로그인한 사용자가 소유한 업로드 이미지·동영상·오디오를 상세 조회한다. 파일 이름, 종류, 생성 시각, 파일 용량을 표시하고, 동영상은 재생 시간과 영상 크기도 표시한다. 업로드 목록의 파일 이름 링크가 상세 페이지로 이동한다.

이미지 상세는 `ImageMedia`와 `ImageEditor`를 사용해 crop, 확대, 회전을 저장할 수 있고, 동영상 상세는 `VideoMedia`와 `VideoEditor`를 사용해 구간, crop, 회전을 저장할 수 있다. 편집 결과는 각각 새 `media_assets`와 Storage 파일로 저장한 뒤 새 업로드 상세로 이동하며 원본은 유지한다. 오디오는 재생과 다운로드만 제공한다.
