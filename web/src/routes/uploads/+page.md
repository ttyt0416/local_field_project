# 업로드 콘텐츠 화면

업로드 메뉴는 사용자가 동영상 생성에 제공한 이미지·동영상·오디오만 표시한다. 생성된 이미지·동영상은 보관함에서 확인하며 업로드 콘텐츠 화면에는 포함하지 않는다. 이미지·오디오·동영상 필터를 제공하며, 업로드 콘텐츠는 I2V·FL2V·R2V 입력으로 재사용할 수 있다. 목록은 선택한 필터 기준으로 한 페이지에 10개씩 표시하며 ChevronLeft·ChevronRight 버튼으로 페이지를 이동한다.

업로드 콘텐츠를 다시 선택하는 동작은 일회성 생성 상태만 설정하고 Storage 업로드를 수행하지 않는다. 실제 업로드는 동영상 생성 submit 시 서버에서 처리한다.

R2V 참조 이미지·동영상·오디오는 `R2V 추가`로 여러 개를 누적할 수 있으며, 선택이 끝난 뒤 `R2V 설정 열기`를 눌러 생성 화면으로 이동한다. 같은 파일을 다시 선택하면 한 번만 유지한다.
