# 업로드 콘텐츠 화면

업로드 메뉴는 사용자의 업로드 이미지·동영상·오디오를 표시한다. `SearchBar`로 filename을 검색하고 최신순·오래된순·이름순으로 정렬하며, 콘텐츠 종류 필터와 페이지 이동을 제공한다. 각 카드에는 파일 용량을 표시하고 파일 이름을 선택하면 `/uploads/{file_id}` 상세 페이지로 이동한다.

상세 페이지에서는 이미지·동영상 편집과 다운로드·삭제를 제공한다. 편집 결과는 원본을 덮어쓰지 않고 새 Storage 파일과 `media_assets` row로 저장하며, 저장 후 새 결과 상세로 이동한다. 동영상 상세에는 분·초 형식의 재생 시간을 표시한다.

업로드 콘텐츠를 다시 선택하는 동작은 일회성 생성 상태만 설정하고 Storage 업로드를 수행하지 않는다. 실제 업로드는 동영상 생성 submit 시 서버에서 처리한다. R2V 참조 선택 UI와 삭제 확인 modal은 기존 계약을 유지한다.
