# 저장 프롬프트

`/saved-prompts`는 프리셋과 별도인 공용 문장 저장소다. 종류(image/video), 이름(100자), 내용(5000자)만 저장하고 생성 모델·파라미터는 받지 않는다. GET은 종류별 목록, POST는 생성, PUT/DELETE는 수정·삭제이며 계정 식별자 없이 공용 데이터를 조회한다. 존재하지 않는 ID에는 404를 반환한다. 이름과 내용은 바깥 공백을 제거하고 공백만 있는 값을 거부한다.

## 공용 사용

Local Field 계정 인증과 사용자별 소유자 인자를 제거하고 콘텐츠·작업을 공용으로 처리한다. 외부 서비스의 API 토큰과 기존 오류 기록은 유지한다.
