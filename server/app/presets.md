# 프리셋 API

`presets`는 `user_id`와 `type`으로 분리되는 사용자 설정 모음이다. 현재 타입은 텍스트-이미지 생성용 `t2i`이며, 저장 요청의 `values`에 포함된 선택 필드만 JSONB로 기록한다. 이름은 식별자가 아니므로 같은 이름도 여러 개 저장할 수 있고, 수정·삭제는 UUID로 구분한다.

- `GET /presets?type=t2i`: 현재 사용자의 t2i 프리셋 목록과 저장된 값 조회
- `POST /presets`: 이름과 선택된 값을 새 프리셋으로 저장. 같은 이름도 여러 개 저장 가능
- `PUT /presets/{id}`: 현재 사용자의 프리셋 이름과 저장 값을 수정
- `DELETE /presets/{id}`: 현재 사용자의 t2i 프리셋 삭제

프리셋 값은 서버에서 생성 요청과 같은 범위로 검증한다. 인증 사용자 외의 프리셋은 조회할 수 없다.
