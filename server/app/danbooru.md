임베딩 API 요청의 헤더·본문·전체 시간과 실패를 공통 유틸로 측정한다.

## 공용 사용

Local Field 계정 인증과 사용자별 소유자 인자를 제거하고 콘텐츠·작업을 공용으로 처리한다. 외부 서비스의 API 토큰과 기존 오류 기록은 유지한다.

## Qwen3 임베딩

Qwen3-Embedding 모델을 사용하는 검색 요청에는 이미지 설명에 맞는 Danbooru 태그를 찾는 영어 지시문을 추가한다. 태그 저장·가져오기용 문서에는 지시문을 추가하지 않는다. Qwen 요청에는 설정된 출력 차원을 전달하며, BGE-M3 요청 형식은 유지한다. API 호출의 기존 시간 측정과 DB 감사 기록을 그대로 사용한다.
