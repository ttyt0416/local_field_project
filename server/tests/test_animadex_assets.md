# 로컬 썸네일 검증

세 종류의 공식 파일명·URL 인코딩, 해시 기반 로컬 경로, 최초 저장과 반복 실행의 외부 요청 생략, 버전·트리거 변경 및 삭제된 파일 재다운로드를 검사한다. 잘못된 WebP·파일 교체 실패·원격 404/503 상황에서 이전 파일·버전 보존, 임시 파일 정리, 실패 재시도 및 missing/failed 집계를 검증한다.

인증 API 상대 URL과 private cache 정책, 잘못된 파일 키·경로 탈출 거부, full 429의 delta 전환 및 CDN으로 토큰 미전달, 동시 가져오기 잠금을 확인한다. 모든 파일은 임시 디렉터리, 모든 네트워크·에러 로그는 mock을 사용한다. 운영 DB나 실제 파일을 교체하지 않는다.

HTTPS 연결 재사용, 오래된 연결의 단일 재연결, CDN 토큰 미전달, 302 미추적과 404 재시도 방지도 검사한다. manifest/index 버전 불일치와 잘못된 동시 다운로드 수는 사전에 거부한다.

이미지 전용 URL은 서명된 종류·파일만 읽을 수 있고 만료되면 거부하는지 검증한다. 서명 없는 요청은 기존 Bearer 인증을 유지하며 익명 접근을 허용하지 않는다. 브라우저에서는 실제 운영 빌드의 캐릭터·아티스트·시리즈 이미지, 확대, 태그 뒤에 추가, 시리즈별 캐릭터 필터를 확인했다.
