# 모델 폴더 변경 검증

TemporaryDirectory 아래의 합성 파일만 사용한다. 원본·중첩·빈 폴더의 이름 변경과 전체 삭제, 비모델·숨김 파일 집계, 삭제 대상 변경 이후 확인 무효화, 활성 다운로드 차단, 기존 빈 폴더 덮어쓰기 방지, 기본 경로·traversal·symlink 보호와 외부 링크 대상 보존을 검증한다. 삭제된 폴더로 과거 다운로드를 재시도해 디렉터리를 재생성하는 것도 막는다. 운영 파일이나 실제 Civitai 다운로드를 사용하지 않는다.

`python -B -m unittest discover -s tests -p 'test_model_*.py'`로 기존 모델 다운로드 검증과 함께 실행한다.

worker의 개인 토큰 조회는 합성 개인 토큰을 반환하도록 모킹해 폴더 취소·삭제 검증은 운영 토큰 저장소나 공용 환경 변수에 접근하지 않는다.
