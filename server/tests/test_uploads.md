# 콘텐츠 원본 조회 회귀 검사

동영상 입력 선택 목록에 포함된 생성 이미지·생성 영상·업로드·편집 업로드의 원본을 같은 file_id로 읽을 수 있는지 검사한다. 원본 조회는 get_reusable_media에 현재 user_id를 전달하고, 업로드 전용 get_media_asset 조회에 의존하지 않아야 한다. 소유권 조회 실패 시 Storage를 호출하지 않고 404를 반환하며 Storage 장애는 기존 503 오류로 전달하는지 확인한다. 기존 상세·편집·삭제의 업로드 전용 소유권 계약도 유지한다. 실제 Storage 파일을 생성하거나 삭제하지 않는다.
