# MiniMax H3 동영상 계약 테스트

세 모드가 각각 올바른 workflow를 사용하고 `SaveVideo` dynamic combo payload를 구성하는지 확인한다. 체크포인트는 MiniMaxH3 폴더의 임의 이름과 중첩 폴더를 허용하고 외부·미설치 경로는 제외하는지 검증한다. 특정 기본 파일 없이 설치된 첫 경로를 사용하며 명시한 steps를 보존한다. 선택 LoRA order, GPU allocator crash를 피하기 위한 Morton off 상태, PDD의 matching file·Euler sigma schedule·EasyCache exclusion, persisted continuation steps와 PDD state도 검증한다. video prompt enhancement는 empty overall plus nonempty segment request, `temperature=0.6`, 설명문 언어 선택과 원문 대사 보존 지시, removed MiniMax expert-role sentence, mode별 strict `shots[]` object schema, server assembly, overall fields, server-side shot order non-revalidation을 검증한다. Shot-level exact `N/A` placeholder는 final shot line에서 제외하고 top-level sound fields의 `N/A`는 유지하는 contract도 검증한다. Explicit scene and shot input은 schema count enforcement 없이 prompt contract로 description, order, action을 유지하고, missing physics detail과 character별 expression and action을 요구하는지도 확인한다. mode를 명시한 asset 해석과 기존 Storage asset 재사용도 검증한다. 테스트는 ComfyUI `/prompt`를 호출하지 않는다.

첫 샷 동작 보존, 영어 설명과 한국어 대사·화면 글자 혼합, 행동·대사에 배분한 field별 길이, 장면 수·언어·R2V에 따른 token budget, labeled image 전달, 잘못된 미리보기 거부, FL2V 종료 시간, R2V 6개 section과 일반 참조 header 중복 방지를 회귀 검사한다.
