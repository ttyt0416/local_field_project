# Qwen 2.1 Turbo 검증

Qwen Turbo 기본값과 모델 격리, 단일 이미지의 원본 기반 출력 latent, 공식 8스텝 sigma 일치, 최대 10장 참조 순서, 잘못된 설정의 업로드 전 거부, 소스 필수와 프리셋 네임스페이스를 검증한다. 실제 생성 품질 검증은 별도로 실행한다.

이미지를 함께 읽는 로컬 LLM 강화의 TextGenerate 연결, 참조 배치 순서, 공식 thinking·샘플링 파라미터, 가중치 미설치 시 개별 실행 차단을 확인한다.

Qwen 폴더의 임의 이름·중첩 모델은 모두 옵션에 포함하고 폴더 밖의 같은 파일명은 제외한다. 인코더·VAE·프롬프트 강화 모델도 용도 폴더에서 찾는다.
