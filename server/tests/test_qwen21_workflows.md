# Qwen 2.1 Turbo 검증

Qwen Turbo 기본값과 모델 격리, 단일 이미지의 원본 기반 출력 latent, 공식 8스텝 sigma 일치, 최대 10장 참조 순서, 잘못된 설정의 업로드 전 거부, 소스 필수와 프리셋 네임스페이스를 검증한다. 실제 생성 품질 검증은 별도로 실행한다.

vLLM의 자연어 개선 결과와 Prefix가 Qwen 인코더에 전달되는지, 원본·참조 연결이 유지되는지, TextGenerate가 추가되지 않는지 검증한다. 개선 결과가 없으면 소스 업로드 전에 거부한다.

Qwen 폴더의 임의 이름·중첩 모델은 모두 옵션에 포함하고 폴더 밖의 같은 파일명은 제외한다. 인코더·VAE도 용도 폴더에서 찾으며 별도 프롬프트 강화 가중치는 요구하지 않는다.
